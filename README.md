# 纸间 · 本地 PDF 阅读器

本地导入 PDF，支持书本翻页、单页/双页、跳页、缩略图、缩放和手势翻页。PDF 不上传服务器；首次启动手势时在浏览器中加载随应用提供的识别模型，摄像头画面仅在当前浏览器内处理。关闭手势会释放摄像头。

## Windows 启动

安装 Node.js 22.12+（或兼容的更新 LTS），推荐双击 `启动阅读器.cmd`。脚本会准备依赖、构建并打开生产预览 `http://127.0.0.1:4190`；首次安装需要网络。保持终端开启，按 Ctrl+C 停止。

也可在 PowerShell 中运行：

```powershell
cd 'D:\githob\书籍交互'
npm.cmd install
npm.cmd run build
npm.cmd run preview
```

打开终端显示的 `http://127.0.0.1:4190`。使用 `npm.cmd` 可避免 PowerShell 对 `npm.ps1` 的执行策略限制。不要直接双击 HTML 文件。开发调试使用 `npm.cmd run dev` 或 `开发模式.cmd`，地址为 `http://127.0.0.1:5190`；开发模式可能回退到主线程识别，请在生产预览中评估手势性能。

部署时提供完整 `dist` 目录，并通过 HTTP 服务访问。手势依赖的 WASM、模型和 PDF worker 均随构建提供，不需要外部 CDN；生产构建使用 classic Worker 运行手部识别。安装依赖需要网络。

## 阅读与手势

拖入或选择 PDF 后，用左右按钮、键盘左右方向键、页码输入框或缩略图翻页。自动布局按视窗宽度选择单页或双页；双页布局把封面单独展示。放大后可拖动画面，点击适合页面恢复视野。文件替换与关闭入口在工具栏。

浏览器只保存阅读位置等小量偏好，不保存 PDF 文件本身。刷新后重新选择同一文件会恢复位置；不同浏览器、隐私模式、清除站点数据或改动文件后可能无法恢复。

手势需要主动开启并授予摄像头权限。请使用 `localhost` / `127.0.0.1` 或 HTTPS；局域网 HTTP 地址通常不能调用摄像头。允许权限后，将手掌放入预览取景框，保持光线均匀。预览为镜像：以预览中手移动的方向为准，向左挥动翻到后页，向右挥动回到前页。

每次挥动后有冷却时间；把手放稳或收回，等待状态复位再进行下一次。连续把手停在一侧不会持续翻页。灵敏度越高越容易触发；误触时降低，动作不易识别时提高，并适当增大挥动幅度。识别失败、摄像头被占用或拒绝权限时，按钮与键盘仍可使用。

## 测试与验收

```powershell
npm.cmd run fixtures
npm.cmd test
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

已有本机 Chrome 时可用 `$env:PLAYWRIGHT_CHANNEL='chrome'` 后运行端到端测试，无需下载 Chromium。测试服务默认使用 5188；端口占用时设置 `$env:PLAYWRIGHT_PORT='5192'`。

可选加密夹具需要 Python 与 `pypdf`：先执行 `python -m pip install pypdf`，再执行 `npm.cmd run fixtures -- --encrypted`。夹具密码为 `zhijian123`。未生成该夹具时仅密码测试标为跳过，其余测试照常运行。

自动生成的 `.test-data` 包含 12 页混合尺寸 PDF（封面、奇偶页、横向、小尺寸）、11 页奇数页、120 页、单页和损坏文件，均为合成测试数据。Playwright 覆盖导入、导航、双页末尾边界、全屏错误提示、布局、缩放后实际图像像素增加、拖动、窄屏、替换、错误恢复、刷新后重选恢复、高清缓存上限、缩略图像素释放、对象 URL 释放和阅读路径无外域 HTTP 请求。手势轨迹单元测试使用合成坐标；摄像头权限失败测试使用模拟拒绝。它们不代表摄像头与真实手掌识别已经通过验收。

发布前仍须在有摄像头的真实设备上检查：

1. Chrome/Edge 中允许、拒绝和撤回摄像头权限；开启与关闭后检查摄像头指示灯。
2. 左右手各完成向左/向右挥动；确认镜像方向、冷却和复位，无停手连翻。调整灵敏度，在弱光、背景干扰和多人入镜时观察误触。
3. 触屏手机与桌面上检查横竖屏、单/双页、横向 PDF、放大拖动和最后一页边界。
4. 使用真实大 PDF 连续快速翻页，再替换、关闭和重开；检查清晰度、内存趋势及浏览器是否持续响应。
5. 使用有权处理的真实密码保护 PDF，补充不同加密算法与文件大小的兼容性检查。自动密码测试使用合成 RC4-128 夹具，覆盖取消、错误密码重试和成功解锁。

自动测试实际运行结果以终端与 Playwright 报告为准。手势识别受摄像头、光照和设备性能影响，真实识别验收必须单独记录。
